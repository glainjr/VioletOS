RFCs that mention IEEE 802.11 and are left out because they do not bear on a station joining a WPA2-Personal network: the CAPWAP documents (RFC 5415, 5416 and those around them), which describe access points and their controllers, and the EAP documents (RFC 3748, 4017, 5247), which a network with a shared password does not use.
